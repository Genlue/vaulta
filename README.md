# vaulta

面向 Windows 的本地数字资产仓库。把现有文件夹加为仓库，或选一个父目录新建仓库。磁盘上的文件照常使用；Vaulta 在其上额外维护 Inbox、主分类、标记和操作历史。不包含 AI 服务，不会自动上传仓库内容。

## 使用

1. 在 **仓库** 添加现有文件夹或新建仓库。用顶栏仓库名称切换当前仓库。默认按磁盘目录进入 **文件**，看到的就是磁盘上的真实层级；新发现的文件进入 **收件箱**，扫描会按扩展名给出分类建议。
2. **资料库** 只列出已入库的资产，并按磁盘文件夹分层显示：文件夹可以逐层展开，里面的文件不会在根层重复出现；工具栏的「展开 / 收起」一次展开全部层级。**文件** 始终显示目录里的全部内容，不受入库状态影响。主分类表示逻辑归属，标记记录重点关注，磁盘目录反映真实位置。重复项、缺失、排除、历史及扫描收在 **仓库工具**。
3. **入库** 表示把资产纳入资料库：状态从「待入库」变为「已入库」，并在没有人工分类时采用扫描给出的分类建议。它只改管理信息，不移动、不复制、不重命名原文件。识别不了的文件留在收件箱，等你决定。如果新加入的是一整个文件夹，收件箱会按文件夹分组，不再把里面的文件铺平；文件夹行上的「整体单元」可以把它作为单一项目入库，内部文件随后在它自己的空间里管理。

   从 0.3.1 及更早版本升级时，原本已经在列表里显示的资产会一次性视为已入库，避免资料库突然变空；升级后新发现的文件才进入收件箱。
4. **关注标记** 是针对个别资产的主动关注行为。可在资产详情中添加标记，也可勾选后批量设置标记。这不会移动文件或改变入库状态。
5. 拖动侧栏右缘可调宽度，拖动右侧详情栏的左缘同样可调宽。键盘聚焦分隔线后按方向键微调（`Shift` 加速），`Home` / `End` 可到两端。宽度会记住。**设置 → 通用** 可在侧边栏与悬浮导航栏之间切换，也可切换窗口标题栏样式。

6. **重定位仓库**：把整个仓库移到同一磁盘卷的其他位置或改名后，从原仓库的 **管理 → 重定位仓库…** 选择新位置，无需移除并重新添加。资产、标签、视图与整体单元保留；软件不会移动文件。跨卷移动或选择副本会被拒绝，不会改写原绑定。
7. **软件更新**：在 **设置 → 软件更新** 查看当前版本或手动检查。桌面应用启动时自动检查，运行期间每 6 小时再检查；只访问 GitHub 更新源，不上传本地仓库。安装版经确认后下载并验证签名，再启动安装程序；便携版从发布页下载压缩包。0.3.21 及更早版本需先手动安装一次此功能所在的版本。

### 快捷操作

- **液态玻璃菜单**：所有菜单和右键菜单都由 GlassDesign 的 `.c-menu` 材质绘制，浏览器自带的右键菜单不再出现。右键内容随位置变化：在资产上是文件操作，在输入框和文本选区上是撤销、剪切、复制、粘贴、全选，在空白处是视图、侧栏和仓库操作。
- **悬浮导航**：**设置 → 通用 → 导航栏形态** 选「悬浮导航栏」后，导航变成左侧居中的玻璃药丸，浮在内容上而不占一列宽度；设置按钮独立在药丸下方，点击顶栏的导航开关可整条收起并让内容铺满左侧。侧边栏模式下，同一枚胶囊随侧边栏展开移到右上角、收起时移回顶栏。
- **快捷指令**：点击顶栏的快捷指令胶囊，或按 `Ctrl+Shift+P`。可按名称查找操作、仓库和已保存视图，方向键选择、回车执行。`Ctrl+K` 聚焦资产搜索。快捷指令和自动详情各占一枚胶囊，互不影响。
- **前进 / 后退**：顶栏左侧的胶囊按钮，或 `Alt+←` / `Alt+→`。记录的是仓库、页面、目录、筛选和排序，不复制文件。
- **浮动顶栏**：红绿灯、侧栏开关、前进后退、仓库、搜索和操作在同一行，每件控件各自套一枚胶囊，间距统一 16px；品牌落在侧栏第二行，不再和胶囊抢位置。顶栏本身透明，内容滚到它下面时才出现渐进模糊。
- **纯色背景**：页面最底层 `#wallpaper` 只是一块 `--canvas` 纯色，不截屏、不轮询；玻璃胶囊在这层纯色上做材质。列表表头随内容一起滚走，顶栏下方只保留一层渐进模糊。
- **排序与文件夹优先**：排序菜单可选名称、修改日期、创建日期、大小、类型或路径，升降序切换。默认开启「文件夹优先」，文件夹在升序和降序下都排在最前；关闭后文件夹按当前排序键与文件混排。
- **网格视图**：名称最多两行，下面依次显示「类型 · 大小」和修改日期；文件和文件夹各用自己的类型图标，便于扫一眼分辨。
- **拖拽移动**：在「文件」或「资料库」里把文件、文件夹拖到普通文件夹的行或卡片上，确认后移动到该文件夹；多选时拖任意一项会带上全部选中项。文件夹不能拖进自身或下级目录，整体单元不接受拖入。真实磁盘路径会改变，不会复制内容。确认框可勾选「不再显示这个提醒」，之后直接移动；**设置 → 通用 → 拖拽移动前确认** 可随时改回每次确认。
- **逐项处理**：在收件箱点「逐项处理」，侧栏会自动预览。可跳过、直接入库，或设置分类与标记后入库；成功后跳到下一项。当前筛选也会缩小待处理范围。跳过不改状态；入库会加入资料库并补上分类建议，但不移动文件。
- **直接预览文档**：单击文件即可在右侧看原版式。PDF 可翻页和缩放，也支持没有文字层的扫描页。PPTX、PPSX 由桌面版 PowerPoint 逐张生成静态预览，可翻页和缩放。Word、Excel 及部分兼容格式使用 Windows 注册的预览器；如果无法渲染，可从侧栏用系统应用打开或在资源管理器中定位。
- **查找文档内容**：在顶栏「范围」菜单开启「搜索文件内容（含文档）」。Vaulta 在本机为搜索尝试提取 `.docx`、`.pptx`、`.xlsx` 和部分有文本层的 PDF；它与右侧的版式预览是独立的。扫描件能预览，但不会做 OCR。
- **保存视图**：用资产页标题旁的星标，把当前仓库、目录或分类、筛选和排序保存到资料库的「视图」菜单。选择视图即可恢复，页标题旁的星标可管理当前视图。视图保存的是规则，不是文件快照；偏好保存在本机当前 WebView 用户配置中，不随 SQLite 数据库同步。

### 数据在哪里？

- 真实文件继续保存在原目录；移除仓库不删除文件。同一真实仓库重新添加时可恢复本地管理信息。
- 本地管理数据在 `%LOCALAPPDATA%\com.vaulta.desktop\vaulta.sqlite3`。备份时应先退出 Vaulta 并停止 Agent 写入，再备份整个应用数据目录；文件内容仍需单独备份。
- 0.3.3 起数据库结构版本为 2。升级后旧版应用会拒绝打开同一份数据库；需要回退时先备份 `vaulta.sqlite3`。
- 外部工具用 `vaulta-agent.exe` 读取和修改管理信息，见 [Agent 协议](docs/agent-api.md)。数据库不是写入接口。
- `.vaulta-views` 是保留目录，不作为普通资产索引。生成的软链接不复制内容，但在资源管理器中**跟随**目录链接后看到的仍是真实文件。不要把它当备份或只读沙箱。仅删除链接本身不会删除目标。

## 开发和打包

Tauri 2 + Rust；前端是随应用打包的 Web 资源，通过 `glass-web`/WASM 挂载真正的 GlassDesign（Leptos）控件，包括液态玻璃胶囊、工具栏、可拖侧栏分隔条、窗口红绿灯、导航、仓库卡片、搜索框、动态菜单、滑动分段控件、按钮、设置选择框、提示及状态栏。原生对话框表单和资产列表仍由 Vaulta 管理。二进制资源随 Windows 应用打包，运行时不访问外部站点。Windows x64 使用 Rust 1.90+ 的 MSVC 工具链、C++ Build Tools、WebView2 和 Tauri CLI 2。

```powershell
cargo tauri dev
cargo test --workspace --locked
node frontend/tests/smoke.mjs
pwsh -NoProfile -File scripts/test-native-windows.ps1
pwsh -NoProfile -File scripts/build-windows.ps1
```

日常改完代码后，双击仓库根目录的 **`rebuild.cmd`** 就能一键重建：它按仓库惯例把补丁版本 +1，结束时列出安装包、便携包路径和 exe 的 FileVersion。常用参数：`-NoBump` 原地重打当前版本，`-Test` 先跑前端冒烟测试，`-SyncGlass` 先同步隔壁 GlassDesign 的玻璃资源，`-Version 0.4.0` 指定版本，`-Offline` 禁用 Cargo 联网，`-NoPause` 结束时不等待按键（给脚本调用）。

该入口只走 PowerShell 7，不兼容 Windows PowerShell 5.1。`rebuild.cmd` 本身是纯 ASCII、先把控制台切到 UTF-8，中文提示放在 UTF-8 BOM 编码的 `scripts/rebuild.ps1` 里，所有路径都用引号和 `-LiteralPath`，因此在中文 Windows、中文路径和含空格的路径下都能正常打包。

打包脚本默认把 patch 版本加一（0.3.0 → 0.3.1），同时改写 `src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 与 `Cargo.lock`，安装包和便携包因此不会互相覆盖。发 minor/major 版本用 `-Version 0.4.0` 指定；只想原地重打当前版本用 `-NoBump`。

发布 Windows x64 更新时，在 `main` 提交并推送版本修改，再运行 `pwsh -NoProfile -File scripts/release-windows.ps1 -Publish`。该脚本生成安装包、便携包、绑定版本号的 Tauri 更新签名和 `latest.json`，上传到 GitHub Release 草稿后才设为最新发布。可省略 `-Publish` 仅生成签名产物；签名器需支持 `--app-version`（例如 Tauri CLI 2.12.6，可用 `-TauriCli` 指定独立 `cargo-tauri.exe`）。更新私钥和密码不进 Git：应使用已有的 `TAURI_SIGNING_PRIVATE_KEY`（或 `TAURI_SIGNING_PRIVATE_KEY_PATH`）及 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`；此电脑也可读取 `%LOCALAPPDATA%\VaultaReleaseSigning` 下受密码保护的密钥和当前 Windows 用户可解密的密码。普通本地构建不要求有签名私钥。更新签名不等同于 Windows Authenticode 代码签名。

普通构建直接使用已检入的 `frontend/vendor/glassdesign`，不要求安装 WASM 工具链。修改相邻的 GlassDesign 仓库后，在 Vaulta 根目录执行 `pwsh -NoProfile -File scripts/sync-glassdesign.ps1` 同步新产物；非默认位置可指定 `-GlassDesignPath`。对应的 `glass-web` 配置、组件属性、事件与生命周期在 GlassDesign 的 `web/README.md`。

`crates/vaulta-core` 管理 SQLite、身份核对、分类和历史；`crates/vaulta-fs` 提供 Windows 文件操作、预览和链接视图；`src-tauri` 提供窗口、后台同步、命令和 Agent CLI；`frontend` 提供界面。

## 范围和限制

- 优先支持可获取 Windows 稳定文件身份的本机卷。扫描跳过重解析点，不跟随符号链接和目录联接。无法安全核对时保留旧记录，且不会用同名或相同内容推断身份。外部跨卷移动不保证保留身份。
- Windows 回收站不可用时不改为永久删除。内置移动不以隐式复制加删除代替跨卷移动；不覆盖目标。执行文件有独立入口和确认，普通打开不用于执行脚本。
- 分类视图需要系统允许创建符号链接。可安全判断的外部变更会反映到分类；歧义报告给用户，不修改原文件。
- 内置预览支持 PDF、常见 Office 文档、文本、常见图片以及 WebView 支持的音视频。PDF 用 Windows PDF 引擎逐页绘制，不依赖 Office；`.pptx` / `.ppsx` 需要桌面版 PowerPoint，按页渲染静态画面，不播放动画；带外链素材或活动控件的文稿请用系统应用打开。`.doc` / `.docx`、`.ppt` / `.pps`、`.xls` / `.xlsx`、`.rtf`、`.odt` / `.odp` / `.ods` 需要系统存在能在独立进程运行的对应预览器。文档版式预览上限 64 MiB。带有 Windows 下载标记的 Office 文档默认暂停预览；信任来源时可在侧栏选「仍然预览…」→「仅本次预览」。这不会解除原文件的下载标记或更改系统设置。遇到受密码保护或无法渲染的文件，可尝试用系统应用打开，旧格式也可在资源管理器中定位。Markdown、代码、纯文本可按其源文本编辑；不执行预览中的 HTML 或脚本。内置保存要求本地 NTFS 支持事务写入，不满足时请使用外部编辑器。内容搜索的文档提取为尽力支持：Office 仅读取正文、幻灯片文字或表格单元格等受支持的内容，不执行宏和公式；PDF 仅支持部分使用传统交叉引用表和基本单字节字体的文本型文件，不做 OCR、不会运行嵌入脚本。内容搜索的文档输入上限 8 MiB，提取文本上限 512 KiB；加密、超限和不支持的文件仍可按名称搜索并交给外部应用。相似度和专业设计格式预览尚未实现。
- 软件能撤销受支持的管理信息变更；真实文件删除从系统回收站恢复，不保证恢复永久删除。详情和验证方法见 [验收与边界](docs/acceptance.md)。
