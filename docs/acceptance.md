# 验收与边界

使用本机 NTFS 上的临时目录进行以下检查。不要用唯一一份重要文件测试真实移动和删除。

| PRD | 操作 / 预期 |
|---|---|
| A01–A05 | 创建一个空仓库并另行添加含文件的目录。在资源管理器新增文本，待扫描后进入 Inbox；不入库即可预览、改标签。 |
| A06–A09、A13 | 给文件设置分类和两个标签，用资源管理器移动、改名；记录仍在，路径更新。组合标签筛选；改分类时磁盘位置不变。 |
| A10–A12 | 启用分类视图，在 `.vaulta-views` 看见链接。在视图各分类目录之间移动链接，只有管理关系变化；删链接时原文件仍在。Windows 不允许建立链接时应显示错误，而不是复制内容。 |
| A14–A15 | 将项目目录设为整体单元；父仓库不再独立列出它的子项，内部可独立分类。 |
| A16–A17 | 给测试仓库开启只读后用 Agent CLI 读取快照。验证写入被拒绝；开启读写后添加标签，界面出现变化。 |
| A18–A19 | 排除后重新扫描，文件不回到 Inbox 且原文件保留。再纳入管理后测试回收操作；必须出现明确确认，取消不删除。 |
| A20 | 在两个仓库中保存同名文件，跨仓库搜索时每条显示所属仓库。 |
| A21–A22 | 编辑 UTF-8 Markdown 并保存，再次验证原文件内容。预览后用其他程序修改文本，应用中的旧草稿不能静默覆盖新版本。 |
| A23–A25 | 创建一个内容相同的副本，重复视图显示两个实体。关闭应用后改名，再启动应保留已有管理关系；用不同文件替换同路径，旧记录应保留为缺失而非继承。 |

`cargo test --workspace --locked` 覆盖核心身份、扫描、组织事务及文件操作用例。不同文件系统、系统符号链接权限和 WebView 媒体编解码器会影响可用能力；错误不应该触发原文件复制、覆盖或永久删除。后台监听失效时依赖定期校验，不承诺所有外部更改都瞬时反映。

## 0.2 工作流

| 操作 | 预期 |
|---|---|
| 按 `Ctrl+Shift+P`，输入「打开收件箱」，按 Enter | 关闭指令面板并进入收件箱；Esc 则仅关闭面板。 |
| 在收件箱逐项处理，跳过首个项目，对下一项选「整理后入库」 | 首个项目不变；下一项的分类、标签和入库状态同时更新，原文件路径不变，自动转到剩余项目。 |
| 设置类型筛选，保存为「只看图像」，切换后从侧栏重开 | 恢复原仓库与筛选；新加入且符合规则的图片会出现。移除视图不改文件或分类。 |
| 从已保存视图用 `Ctrl+K` 搜索，再清除搜索 | 回到搜索前的视图、筛选与排序。 |
| 在 `.docx` / `.pptx` / `.xlsx` 或受支持的文本 PDF 中放入仅存在于正文的关键词，再打开内容搜索 | 匹配项出现；详情预览显示只读提取文本，不可以写回。失效文件仍可按名称查找。 |
| 切换深浅外观，打开搜索范围和排序菜单，使用方向键和 Esc | 使用 GlassDesign 渲染控件，弹层可用且正确关闭，浏览器控制台不应出现 WASM 错误。 |

## 0.3 浏览与入库

| 操作 | 预期 |
|---|---|
| 打开仓库 | 默认进入「文件」，显示仓库根目录的文件夹和散落文件，不递归铺开子目录内容。 |
| 顶栏 | 红绿灯、侧栏开关、品牌、前进后退、仓库、搜索在同一行；顶栏无实心底色，内容滚到其下方时出现渐进模糊。 |
| 前进 / 后退 | 顶栏胶囊或 `Alt+←` / `Alt+→` 在仓库、页面、目录和筛选之间往返；按钮在无历史时禁用。 |
| 单击一个文件 | 右侧直接显示预览；不出现行首勾选框或批量操作条。Ctrl/Shift 点击或点勾选框才进入多选。 |
| 把 `.md` / `.docx` / `.png` / `.zip` 放入仓库并扫描 | 收件箱中出现对应资产，主分类已建议为文档 / 图片 / 压缩包；状态仍是「待入库」。未知扩展名保持未分类。 |
| 在收件箱点「全部入库」 | 资产离开收件箱并进入「资料库」；「文件」中仍然显示，磁盘路径不变。 |
| 把某个目录设为整体单元 | 父仓库的「文件」把它作为单个项目，不展开子项；进入后在自己的空间浏览。 |

浏览器冒烟使用本机 Edge 和模拟 Tauri IPC，验证实际 WASM 控件和交互，不代替 NTFS、回收站、或真实系统文件对话框测试。
